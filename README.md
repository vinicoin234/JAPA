# Japa Update

Your Gateway to Global Travel & Work Opportunities for Nigerian Citizens.

Japa Update provides daily, verified information about visa requirements, work permits, and study opportunities across all countries (Canada, United Kingdom, Germany, Australia, United States, Ireland, Netherlands, UAE, and more).

## Tech Stack
- **Framework**: React 18 SPA (Vite)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **State & Auth**: React Context with LocalStorage persistence
- **Payment Integration**: Paystack simulation & subscription tiers

## Key Features
- **Global Country Visa Database**: Detailed pathways (Express Entry, Skilled Worker, Chancenkarte, EU Blue Card, Student Visas) with Proof of Funds (POF in NGN and foreign currency), processing times, and requirements.
- **Relocation Document Checklist**: Interactive progress tracker for International Passport, IELTS/PTE, WES credential evaluation, police clearance, and funds.
- **Automated Daily Immigration News**: Monitored updates from official UKVI, IRCC, and European immigration portals.
- **Paystack Subscription Flow**: Basic Access (₦1,000/mo) and Premium Access (₦2,500/mo) checkout.
- **Authentication**: Sign in, register, and applicant dashboard.

## Development

```bash
npm install
npm run dev
```
